🏥 Jeevanta — Backend API Server

Real-Time Hospital Bed & Ambulance Booking API with Gemini AI Medical Consultation.

REST API Endpoints

Method Endpoint Description
GET /api/hospitals Fetch all hospitals with available bed counts
POST /api/book-bed Atomically reserve a hospital bed
POST /api/book-ambulance Reserve hospital bed and dispatch ambulance
POST /api/ai-consult Gemini AI medical query & allergy triage
GET /doctors List available doctors and specializations
POST /api/users User login and user registration
